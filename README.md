\# MCP Power Bridge



A custom local Model Context Protocol (MCP) server built with Python and FastMCP to bridge AI assistants with local filesystem scanning, database querying, and system automation.



\## Features

\- Local SQLite database querying (`query\_database`, `find\_sqlite\_files`)

\- Calculation engine (`calculate\_cgpa`)

\- Extensible architecture for local OS automation



\## Setup

1\. Clone the repository

2\. Install dependencies (`mcp`, `fastmcp`)

3\. Run `server.py` via your MCP-compatible client configuration.
